# Contributing

Contributions are welcome. For larger changes, open an issue first to discuss the approach. Keep the application usable offline, preserve the local-first data model, and clearly document any feature that sends information to an external service.

## Development

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm start` to launch the desktop app.
4. Keep credentials, OAuth client secrets, personal library data, and exports out of commits.
