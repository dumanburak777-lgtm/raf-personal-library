# Security policy

RAF stores its local library encrypted on the user's device. Optional Google sign-in and Discourse connections use external services; see the README and in-app privacy notice for the data flows.

Please report security issues privately to the repository maintainers rather than opening a public issue with exploit details. A private reporting channel can be configured in the repository's GitHub security settings after publication.

Do not include real passwords, OAuth tokens, forum API keys, private messages, or personal library exports in bug reports.
